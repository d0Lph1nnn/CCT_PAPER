# CCT (Compact Convolutional Transformer) - Flowers Image Classification

Bu proje, Compact Convolutional Transformer (CCT) mimarisinin **Flowers** (Çiçekler) veri seti üzerinde uygulanmasını ve eğitilmesini içermektedir. 

Geleneksel Vision Transformer (ViT) modellerinin aksine, daha küçük veri setlerinde yüksek performans göstermesi için tasarlanan CCT mimarisi kullanılarak görüntü sınıflandırma (image classification) görevi gerçekleştirilmiştir.

## 📊 Performans ve Sonuçlar
* **Veri Seti:** Flowers Dataset
* **Model:** Compact Convolutional Transformer (CCT)
* **Test Doğruluğu (Accuracy):** %70

## 🛠️ Kullanılan Teknolojiler
* **Python**
* **PyTorch** (Derin Öğrenme Framework'ü)
* **Jupyter Notebook** (`CCT_PAPER.ipynb`)

## 📂 Dosya Yapısı
* `CCT_PAPER.ipynb`: Veri ön işleme, modelin oluşturulması, eğitim döngüsü (training loop) ve test aşamalarının bulunduğu ana geliştirme dosyası.
